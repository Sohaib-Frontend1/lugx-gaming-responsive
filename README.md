# LUGX Gaming — Responsive Implementation

A responsive adaptation of the LUGX Gaming landing page. The original project and visual design were created by Yahya. The responsive implementation, mobile navigation, and layout optimization were completed by [Your Name].

## Project Overview

This repository contains the LUGX Gaming landing page adapted for desktop, tablet, and mobile screens. The goal of this work was to preserve the original visual direction of the project while improving how the layout behaves across different viewport sizes.

The original project and design belong to Yahya. This repository documents the responsive implementation work performed on top of that original work.

## Scope of Contribution

The responsive work in this repository includes:

- Implementing CSS media queries for desktop, tablet, and mobile breakpoints.
- Adding a mobile navigation menu using a hamburger menu pattern.
- Adjusting the header layout for smaller screens, including spacing and alignment.
- Converting the hero section into a vertical, stacked layout on tablets and phones.
- Making the trending games, most played games, and category cards wrap and stack correctly on smaller viewports.
- Optimizing the search bar and search button behavior on narrow screens.
- Adjusting the footer, contact form container, and general spacing for mobile devices.
- Testing and refining layout behavior at the following breakpoints:
  - 1400px
  - 992px
  - 768px
  - 425px
  - 320px

## Pages

- `index.html` — Main landing page containing the hero section, trending games, most played games, and top categories.
- `contactUs.html` — Contact form page.
- `style.css` — Shared styling and responsive rules for all pages.

## Technologies Used

- HTML5
- CSS3
- Flexbox

## Responsive Breakpoints

The layout is adjusted at the following breakpoints:

| Breakpoint | Target |
|------------|--------|
| max-width: 1400px | Large desktop and small laptop screens |
| max-width: 992px | Tablets and small laptops |
| max-width: 768px | Small tablets and large phones |
| max-width: 425px | Standard mobile phones |
| max-width: 320px | Small mobile phones |
